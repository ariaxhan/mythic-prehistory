# Build a level-30 enchanting table in Mythic Prehistory

🔧 **Ready to build**

**Use 15 regular bookshelves in a 5×5 ring, leaving one entrance and a completely empty one-block gap around the table.**

```text
TOP VIEW, SAME FLOOR LEVEL

[B][B][B][B][B]
[B][.][.][.][B]
[B][.][E][.][B]
[B][.][.][.][B]
[B][B][ ][B][B]
       entrance
```

| Mark | Block |
|---|---|
| `E` | Enchanting table |
| `B` | Regular bookshelf |
| `.` | Air; leave it empty |

- Total bookshelves: **15**.
- The bookshelves can be level with the table as drawn.
- Do not place torches, carpet, candles, snow, or decorations in the air gap.
- Insert lapis and an item; the bottom enchantment choice should require level **30**.

Ensorcellation adds enchantments to this pack but does not replace the vanilla bookshelf formation.
